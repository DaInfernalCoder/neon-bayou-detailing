# Neon Bayou Mobile Auto Detailing

Dependency-free marketing website for Neon Bayou Mobile Auto Detailing Houston Texas.

## Contact paths

- Telephone: +1 346-645-6236
- Appointments: https://cal.com/sumitdatta/auto-detail-service

The site intentionally has no public form or email route.

## Local preview

```bash
python3 -m http.server 4174
```

Then visit `http://127.0.0.1:4174`.

## Validation

```bash
python3 scripts/preflight_site.py .
python3 scripts/browser_qa.py
```

## Image use

Launch photography is licensed stock material documented in `SOURCES.md`. It is service context and
